## Что это за продукт

**Detail Pro CRM** (detailprocrm.ru) — SaaS для студий автодетейлинга. Веб-приложение, работает в браузере на компьютере и на телефоне (адаптивная вёрстка, удобно с мобилы).

## Регистрация и доступ

1. Регистрация на https://detailprocrm.ru — email, пароль, название студии
2. Сразу даётся **7 дней бесплатного триала** (полный функционал, без карты)
3. Вход потом туда же — detailprocrm.ru
4. После триала доступ блокируется до оплаты тарифа. Все данные сохраняются.

## ГЛАВНАЯ НАВИГАЦИЯ — две зоны

### 1. TabBar — нижняя панель на телефоне (вверху или сбоку — на десктопе)

Четыре основных раздела:

- **Клиенты** (иконка человечков) — список всех клиентов студии
- **Задачи** (иконка галочки в квадрате) — список задач сотрудникам
- **Календарь** (иконка календаря) — записи клиентов
- **Финансы** (иконка круговой диаграммы) — операции и аналитика. Видна только владельцу и менеджеру с правом `can_view_finance`. Мастер не видит вообще.

### 2. UserMenu — слева сверху, аватар/имя пользователя

Клик по аватарке (или имени рядом с аватаркой) в **левом верхнем углу** открывает выпадающее меню. В меню:

- **Профиль** — личные данные, реквизиты, тариф, прайс-лист, реферальная программа
- **Админ-панель** — управление сотрудниками и активность (видна **только владельцу**)
- **Материалы** — раздел в разработке (заглушка)
- **Выйти**

⚠️ Раздела «Студия» с иконкой здания **НЕ СУЩЕСТВУЕТ**. Я раньше так путала — это неправильно.

## АДМИН-ПАНЕЛЬ (только для владельца)

**Как открыть:** левый верхний угол → клик по аватару/имени → пункт **«Админ-панель»** в выпадающем меню.

Заголовок экрана: «Админ-панель». Вверху три вкладки:
1. **Сотрудники**
2. **Активность**
3. **Аналитика**

### Вкладка «Сотрудники»

Список карточек всех сотрудников студии. На каждой карточке: аватар, имя, роль, статус (активен/заблокирован), последний вход.

**Чтобы добавить нового сотрудника:**
- В правом верхнем углу — **круглая оранжевая кнопка с иконкой «+ человечек»** (это иконка UserPlus)
- Нажимаешь → открывается модалка «Добавить сотрудника»
- Заполняешь: Имя, Email, Временный пароль (можно сгенерировать кнопкой обновления, или ввести вручную), Роль (Менеджер или Мастер)
- Раздел «Доступ к разделам» — для Клиенты/Задачи/Календарь/Финансы выбираешь Скрыт / Просмотр / Полный
- Можно нажать **«Пресет: Менеджер»** или **«Пресет: Мастер»** — права заполнятся автоматически
- Сохраняешь — сотруднику приходит письмо с временным паролем

**Действия с уже добавленным сотрудником (кнопки внизу его карточки):**
- **Редактировать** (иконка карандаша) — поменять имя, роль, доступы
- **Сброс пароля** (иконка ключа) — выдаёт одноразовый временный пароль (показывается ОДИН раз, потом теряется — нужно скопировать и отправить сотруднику)
- **Заблокировать / Разблокировать** (иконка щита) — отключить доступ без удаления
- **Удалить** (красная иконка корзины)

⚠️ У владельца на своей карточке кнопок других нет, кроме **«Изменить пароль»** (для собственного пароля).

**Лимиты пользователей по тарифу:**
- Соло: 1 пользователь (только владелец, добавить сотрудников нельзя — нужен апгрейд на Студию)
- Студия: 3 пользователя в базовой цене (владелец + 2 сотрудника)
- Студия + доп. пользователи: +1 000 ₽/мес за каждого, лимита нет
- Триал: 3 пользователя (как Студия)

При попытке добавить сверх лимита кнопка **«+»** становится серой и показывает подсказку: *«Все 3 слота заняты — добавьте доп. пользователя в Профиле»*.

### Вкладка «Активность»

Журнал всех действий сотрудников: кто, что, когда. Хранится 90 дней.

**Фильтры:**
- Дропдаун **«Все сотрудники»** или конкретный сотрудник
- Дропдаун **«Все действия»** или конкретный тип действия
- Диапазон дат: поля **«С»** и **«По»**
- Кнопка **«Сбросить фильтры»**

**Кнопки:** **«Обновить»** (вручную перезагрузить лог), **«Загрузить ещё 50»** (пагинация по 50 записей).

### Вкладка «Аналитика»

Дашборд с метриками студии. Доступна на любом тарифе.

⚠️ Если клиент спрашивает «где аналитика?» — отвечай: левый верхний угол → клик по имени → **«Админ-панель»** → вкладка **«Аналитика»**.

## ПРОФИЛЬ

**Как открыть:** левый верхний угол → клик по аватару/имени → пункт **«Профиль»** в выпадающем меню. Доступно всем (что внутри видно — зависит от роли).

Профиль состоит из свёрнутых блоков (раскрываются по клику):

### Блок «Личные данные»
- **Имя**, **Фамилия** — редактируются
- **Телефон** — формат +7 (XXX) XXX-XX-XX
- **Email** — только просмотр
- **Аватар** — загрузить или удалить

### Блок «Telegram»
- Кнопка **«Подключить Telegram-бот»** — генерирует одноразовую ссылку на @crmdetailpro_bot
- Если бот привязан: показывает имя пользователя в Telegram + кнопка отвязки

### Блок «Студия» (только владелец)
- **Название студии**
- **Город**
- Прочие поля идентификации

### Блок «Реквизиты для документов» (только владелец)
Подзаголовок: «Используются в шапке актов приёмки авто и заказ-нарядов».
- **ИНН** (10 или 12 цифр)
- **ОГРН / ОГРНИП** (13 или 15 цифр)
- **Юридический адрес**
- **Фактический адрес студии**
- **Телефон студии**
- **Email студии** (для счетов)
- **Текст гарантии** — подставляется в заказ-наряды по умолчанию

### Блок «Утренняя сводка в Telegram» (только владелец)
- Чек-бокс «получать ежедневную сводку»
- Поле выбора времени — например, 09:00
- Сводка приходит в Telegram-бот: записи на день, выручка вчера, задачи

⚠️ Только на тарифе Студия. На Соло/Триале — функция недоступна.

### Блок «Демо-данные» (только владелец)
Подзаголовок: «Заполнить или очистить примеры клиентов и записей».
- Кнопка для создания/удаления демо-данных в свежей студии — чтобы быстро посмотреть как всё выглядит с реальными данными.

### Блок «Прайс-лист услуг» (владелец и менеджер)
Подзаголовок: «Используются при создании заказ-наряда».

Таблица: Название / Цена, ₽ / кнопка удаления.

**Действия:**
- Изменить любую ячейку — сохраняется автоматически после клика мимо (onBlur)
- Кнопка **«+ Добавить»** — поля для названия и цены, кнопка «Добавить»
- Удаление — с подтверждением *«Удалить услугу «X»?»*

Мастер видит сообщение: *«Только владелец и менеджер могут редактировать прайс»*.

### Блок «Подписка» — тарифы и оплата

Карточка текущего тарифа: название, дней до конца, прогресс по слотам.

Дальше — **карточки тарифов** для апгрейда / оплаты:
- **Соло** — 3 900 ₽/мес или 39 000 ₽/год (−16%)
- **Студия** — 5 900 ₽/мес или 59 000 ₽/год (−16%)

На карточке Студия — степпер «−/+» для добавления доп. пользователей (по 1 000 ₽/мес каждый, лимита нет).

Кнопки: **«Оплатить в месяц»** или **«Оплатить в год»** на каждой карточке.

**Оплата идёт через Prodamus** (карта или СБП). Чек на email после оплаты, доступ продлевается автоматически.

**Бонусный баланс** (если есть бонусы за рефералов) автоматически вычитается из суммы.

### Блок «Реферальная программа» (только владелец)
- Реферальная ссылка студии
- Бонус: **1 250 ₽** за каждого приглашённого, кто оплатил тариф (не за регистрацию — за реальную оплату)
- Бонусы накапливаются на бонусном балансе студии и автоматически идут в зачёт следующей оплаты тарифа
- Денежного вывода нет — только в счёт оплаты CRM

### Импорт клиентов из Excel (доступ владельца и менеджера)
Доступен в Профиле в одной из секций.

Мастер импорта:
1. **Скачать шаблон** — даёт готовый .xlsx с нужными колонками
2. **Загрузить файл** — выбор .xlsx с клиентами
3. **Превью** — показывает: всего строк, валидных, с ошибками; первые 20 строк в таблице
4. **Стратегия:** Пропустить дубликаты (по умолчанию) / Перезаписать / Создать новых
5. **Кнопка «Загрузить N строк»**
6. **Результат:** создано / обновлено / пропущено + список ошибок

Лимит — 5000 строк за раз.

## РАЗДЕЛ КЛИЕНТЫ (Tab Клиенты)

Список карточек клиентов. На карточке: аватар, имя, телефон, авто, сумма «всего принёс», дата последнего визита.

**Чтобы создать клиента** — кнопка **«+»** в верхней части экрана. Форма: Имя, Телефон, Авто, Город, Дата рождения, Заметка.

**Карточка клиента (открывается по клику)** — модалка на мобильном, боковая панель на десктопе.

### Сверху
- Большой аватар (можно загрузить или удалить)
- Имя, телефон
- Три кнопки связи: **«Позвонить»**, **«WhatsApp»**, **«Telegram»**

### Поля карточки
- Авто, Город, Дата рождения, В базе с (дата создания)
- **«Всего принёс»** — карточка с суммой выручки от клиента и числом записей
- **«Заметка»** — текстовая заметка по клиенту

### Раскрываемый блок «Запись»
- Кнопка **«+ Добавить»** — создать новую запись (форма: Услуга, Категория, Дата, Время, Мастер, Сумма)
- Активные записи (не выполнены): редактировать / **«Выполнено»** (отметить) / удалить
- Внизу карточки записи — кнопки документов: **«Акт приёмки»**, **«Заказ-наряд»**
- **«Архив записей (N)»** — раскрыть выполненные записи. Кнопка **«Восстановить»** возвращает в активные.

### Раскрываемый блок «Задачи»
- Кнопка **«+ Создать»** — создать задачу, привязанную к клиенту
- Активные задачи + архив выполненных

## РАЗДЕЛ КАЛЕНДАРЬ (Tab Календарь)

Месячная сетка с записями.

- Заголовок «Календарь»
- Кнопка **«+»** в углу (если есть права) — создать новую запись
- Навигация по месяцам: **«< Месяц | Год | >»**
- Сетка 7 столбцов (Пн-Вс), на каждом дне — точки-индикаторы
- Клик по дню → открывается шторка снизу со всеми записями этого дня
- В шторке — кнопка **«Добавить»** для создания записи в этот день

**Форма «Новая запись»:**
- Поиск клиента с автодополнением, или **«+ Добавить клиента»** прямо из формы
- Услуга, Категория, Теги, Мастер, Дата, Время, Сумма
- Кнопка **«Добавить»**

Мастер видит календарь только в режиме просмотра — без кнопки **«+»**.

## РАЗДЕЛ ЗАДАЧИ (Tab Задачи)

Список задач для сотрудников.

- Заголовок «Задачи», справа кнопка **«+»** (если есть права) — новая задача
- Вкладки-фильтры:
  - **сегодня N** — на сегодня + просроченные
  - **задачи N** — все активные задачи
  - **записи N** — все записи клиентов

Группировка списка: «СЕГОДНЯ И ПРОСРОЧЕННЫЕ» / «ЗАПЛАНИРОВАННЫЕ».

Карточка задачи: чек-бокс отметки выполнения, заголовок, имя клиента (если привязан), дата+время, индикатор срочности (красный для срочных), кнопки edit/delete.

**АРХИВ (N)** — раскрыть выполненные.

**Форма «Новая задача»:**
- Название
- Выбрать клиента (необязательно)
- Дата, Время
- Кнопка **«Срочная задача / Обычная задача»** (переключатель)
- Кнопка **«Добавить задачу»** или **«Сохранить изменения»**

## РАЗДЕЛ ФИНАНСЫ (Tab Финансы)

Доступ: владелец, менеджер с разрешением `can_view_finance`. Мастер не видит никогда.

Две вкладки сверху: **«ОПЕРАЦИИ»** / **«АНАЛИТИКА»**.

### Вкладка ОПЕРАЦИИ

- Заголовок «Финансы»
- Иконка **«+»** — добавить операцию
- Иконка **«↓»** — экспорт в Excel

**Карточка БАЛАНС за месяц** (оранжевый градиент сверху): большая сумма, разбивка «Доходы: +X / Расходы: −Y».

Лента операций сгруппирована по датам.

**Форма операции:**
- Переключатель **«Доход / Расход»**
- Название (например, «Зарплата», «Аренда»)
- Сумма
- Дата + Время
- Описание
- **Категория** — теги-кнопки, можно создать через **«+ Добавить»**
- **Теги** — множественный выбор
- Кнопка **«Добавить операцию»** или **«Сохранить»**

### Вкладка АНАЛИТИКА

- Переключатель **«Расходы / Доходы»**
- Кнопки **«День / Неделя / Месяц / Год»**
- Навигация по датам стрелками
- Карточка с общей суммой за период
- Круговая диаграмма по категориям + легенда
- Развернуть категорию — увидеть разбивку по тегам и операциям

## ДОКУМЕНТЫ — Акт приёмки и Заказ-наряд

Открываются с карточки клиента → блок «Запись» → нижние кнопки **«Акт приёмки»** и **«Заказ-наряд»**.

### Акт приёмки

Модалка с разделами:
1. **Заказчик:** ФИО, Телефон (подтянутся из карточки клиента, если есть)
2. **Автомобиль:** Марка, Модель, Год, Цвет, Госномер, VIN
3. **Пробег, км**
4. **Состояние кузова — 16 зон.** На каждой зоне можно нажать **«Царапины»** (жёлтое) или **«Вмятины»** (красное). Если ничего не нажато — зона в норме.
5. **Описание повреждений** (текст до 5000 символов)
6. **Ценные вещи в салоне** (текст до 2000 символов)
7. **Фото** — загрузка нескольких
8. **Подпись заказчика** — рисуется пальцем или мышкой прямо на экране

Внизу: **«Закрыть» / «Скачать PDF» / «Сохранить»**.

### Заказ-наряд

1. Заказчик и Автомобиль (как в акте)
2. **Перечень работ:**
   - **«Из прайса»** — модалка выбора услуг из прайс-листа студии
   - **«Вручную»** — добавить пустую строку
   - На строке: название, количество × сумма, кнопка удалить
3. **Итоги:** сумма работ, скидка ₽, итого
4. **Способ оплаты:** Наличные / Карта / Перевод
5. **Дата выдачи**, **Время выдачи**
6. **Гарантия** — если оставить пустым, подставится из реквизитов студии (поле «Текст гарантии» в Профиле)
7. **Комментарий**
8. **Подпись заказчика**

Внизу: **«Закрыть» / «Скачать PDF» / «Сохранить»**.

## РОЛИ

### Владелец (owner)
- Полный доступ ко всему
- Только владелец видит **«Админ-панель»** в верхнем меню
- Только владелец может покупать тарифы, менять реквизиты студии, видеть реферальную программу

### Менеджер (manager)
- Видит TabBar: Клиенты, Задачи, Календарь
- Видит **Финансы** только если в правах включён `can_view_finance` (по умолчанию — да)
- Видит **Прайс-лист** в Профиле, может редактировать
- НЕ видит **«Админ-панель»** в верхнем меню
- НЕ видит большинства блоков Профиля (только свои Личные данные, Telegram)
- Может: создавать/редактировать клиентов, записи, задачи, услуги, операции

### Мастер (master)
- Видит TabBar: Клиенты (просмотр), Задачи, Календарь (просмотр)
- НЕ видит **Финансы** никогда (хардкод, даже если кто-то поставит галочку)
- НЕ видит **«Админ-панель»**
- НЕ редактирует прайс — видит сообщение *«Только владелец и менеджер могут редактировать прайс»*
- Может только смотреть, в задачах ставить отметки выполнения. Не создаёт/удаляет.

## Что CRM НЕ делает (важно — не выдумывай)

- Не отправляет SMS клиентам (только Telegram-уведомления для сотрудников)
- Нет интеграции с 1С, Битрикс24
- Нет онлайн-записи для клиентов через сайт (только внутренняя запись сотрудником)
- Нет нативного мобильного приложения (PWA / адаптивный сайт)
- Нет складского учёта материалов (раздел Материалы — заглушка)
- Нет email-рассылок клиентам
- Нет автоматического расчёта зарплаты мастерам (через Финансы вручную)
- Нет публичного API
- Нет интеграции с онлайн-кассами
- Нет двух студий на одном аккаунте — один аккаунт = одна студия

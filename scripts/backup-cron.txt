# Архивный пример. Прямой cron-запуск backup.sh больше не поддерживается:
# PostgreSQL и var/ должны сниматься при остановленных записях приложения.
# Используйте saas-crm-backup.timer + saas-crm-backup.service. Журнал:
#     journalctl -u saas-crm-backup.service
# Старую строку cron с scripts/backup.sh необходимо удалить после включения
# и проверки systemd timer, иначе она будет завершаться безопасной ошибкой.

# Опционально — еженедельная чистка протухших сессий (понедельник 03:30):
30 3 * * 1 cd /var/www/saas-crm && /usr/bin/node -e "require('./server/lib/auth.cjs').cleanupExpiredSessions().then(n => console.log('cleaned ' + n + ' sessions')).catch(e => { console.error(e.message); process.exit(1); })" >> /var/log/saas-cron.log 2>&1
